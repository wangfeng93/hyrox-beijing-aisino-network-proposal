# HYROX 北京赛事 × 航天信息网络合作企划

本项目是一份用于受控展示的单页合作企划，方案面向 **2026 年 9 月 10–13 日 HYROX 北京赛事**，场馆为 **北京冰丝带（国家速滑馆）**。

## 方案定位

| 项目 | 说明 |
| --- | --- |
| 方案策划与制作 | 航天信息（Aisino） |
| 主要网络产品体系 | 锐捷网络（Ruijie Networks） |
| 核心目标 | 保障注册、赛事直播、Merch/赞助商交易和工作人员办公等关键业务的连续性 |

## 使用方法

在受控环境中打开 `index.html` 即可查看。网页的动态拓扑、场景切换与图片全屏查看等核心功能可以离线运行；外部案例和参考来源链接需要联网访问。

## 动态拓扑

动态拓扑提供正常运行、专线抖动、旁路 A 故障、注册高峰和交易高峰五个场景。场景用于说明抗干扰布线、跨境专线、双旁路软件路由、链路质量探测、择优路由、锐捷核心/无线产品和业务 QoS 的协同逻辑，不代表北京现场实时监控或实测数据。

## 重要边界

深圳布局图和 28 个需求单元、350M 标注带宽仅作为同类 HYROX 赛事的历史参考样本，不是北京站最终点位、设备数量或互联网出口规格。北京站正式方案需在北京冰丝带完成现场勘察，并确认终端并发、直播上行、公众网络范围、场馆现网和运营商资源。
